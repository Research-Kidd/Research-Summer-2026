# Welcome to Research 2026 Repo
This place is a management area for your research project and code. Any work you commit to your GitHub will be visible for your research group! Each student has their own folder to work in, so feel free to organize it however you want. Additionally, there are some folders containing examples of markdown files, labeled with the .md extension, and .py code. Markdown files are similar to overleaf and are another way to write information down (like what I'm doing!). There is also a folder containing all the REU files/information. Feel free to use this space however you want!

The repo includes an `index.html` file (so it can render a web page), two GitHub Actions workflows, and a CSS stylesheet dependency.
